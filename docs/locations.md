# State, district and city dropdowns

Address forms in the Business App (business registration and the station
form) pick the address as three cascading dropdowns:

1. **State** (36 states and union territories)
2. **District**, loaded for the chosen state (about 800)
3. **City / town**, loaded for the chosen district (about 4,400)

Every list ends with **Other (not in the list)**. Choosing it shows a text
field. When the form is saved, the typed value is stored on the station or
business as usual and a *location request* goes to ChargeKaro. If the state
is new, district and city are typed too; one request covers the whole
address.

## Admin review

Admin Panel → **Locations** lists the requests (staff with the
`locations.manage` permission; admins have it by default). Approve lets the
admin correct the spelling and adds the value, plus any new parent district
or state, to the lists for everyone. Reject needs a reason. The requester
gets an in-app notification either way; staff get one for each new request.

## Database

Migration `20261102000100_locations.sql`:

- `location_states`, `location_districts`, `location_cities`: readable by
  anyone (also before sign-in), written only by the functions below.
- `location_requests`: the "Other" values. Users see their own, staff with
  `locations.manage` see all.
- `request_location(kind, state, district, city, context)`: returns
  `{status: 'exists'}` when the value is already listed, otherwise creates
  (or reuses) a pending request.
- `decide_location_request(id, approve, note, state, district, city)`.
- `businesses.registered_district` and a `p_registered_district` argument on
  `create_business`.

Tests: `supabase/tests/locations.test.mjs`.

## Seed data

Generated by `scripts/locations/build.py` into the migration:

- States and districts: npm package `india-location-kit` (MIT), plus the
  eight Tripura districts it lacks.
- Cities and towns: the countries-states-cities database
  (`@countrystatecity/countries`, ODbL 1.0), each placed in the district of
  the nearest India Post office (`india-pincode`, MIT). A district with no
  town in that data gets its own name, usually its headquarters.

To regenerate, download those packages into a folder and run
`LOCATION_DATA=<folder> python3 scripts/locations/build.py out.sql`. Because
lists also grow through approved requests, add new data in a new migration
with `on conflict do nothing` rather than editing this one.
